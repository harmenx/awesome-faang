## Coding

- [LeetCode](https://leetcode.com) - Coding problems with company tags, contests, and editorials.
- [NeetCode](https://neetcode.io) - Video walkthroughs and a topic roadmap for coding interviews.
- [Tech Interview Handbook](https://www.techinterviewhandbook.org) - Practical preparation guide for software engineering interviews.
- [Grind 75](https://www.techinterviewhandbook.org/grind75) - Customizable 75-question coding plan ordered by study time.
- [Blind 75](https://leetcode.com/discuss/general-discussion/460599/blind-75-leetcode-questions) - Original list of 75 frequently asked coding questions.
- [LeetCode Patterns](https://seanprashad.com/leetcode-patterns) - Free coding questions grouped by the pattern that solves them.
- [Interview Cake](https://www.interviewcake.com) - Interactive lessons that teach how to derive coding solutions.
- [AlgoMonster](https://algo.monster) - Pattern-first course for coding interview questions.
- [Grokking the Coding Interview](https://www.educative.io/courses/grokking-coding-interview) - Interactive course covering the patterns behind coding questions.
- [Hello Interview Coding](https://www.hellointerview.com/learn/code) - Visual lessons on coding patterns used in interviews.
- [Big-O Cheat Sheet](https://www.bigocheatsheet.com) - Time and space complexity for common data structures and algorithms.
- [VisuAlgo](https://visualgo.net/en) - Animations of data structures and algorithms.
- [CP-Algorithms](https://cp-algorithms.com) - Explanations and implementations of algorithms used in interviews.

## System Design

- [System Design Primer](https://github.com/donnemartin/system-design-primer) - Open study guide for large-scale system design interviews.
- [System Design in a Hurry](https://www.hellointerview.com/learn/system-design/in-a-hurry/introduction) - Short system design course written by interviewers from large technology companies.
- [ByteByteGo](https://bytebytego.com) - Diagrams and written guides for system design interviews.
- [Grokking the System Design Interview](https://www.educative.io/courses/grokking-the-system-design-interview) - Interactive course of common system design questions.
- [System Design Course](https://github.com/karanpratapsingh/system-design) - Free illustrated course on designing systems at scale.
- [Aced System Design Guide](https://www.aced.io/blog/system-design-interview-guide) - Preparation guide for system design interviews, updated in 2026.
- [Google SRE Book](https://sre.google/sre-book/table-of-contents) - Free book on building and operating reliable production systems.
- [AWS Well-Architected](https://aws.amazon.com/architecture/well-architected) - Official framework for secure, reliable, and efficient cloud systems.

## Low-Level Design

- [Grokking the Low Level Design Interview](https://www.educative.io/courses/grokking-the-low-level-design-interview-using-ood-principles) - Object-oriented design questions and worked solutions.

## Behavioral Interviews

- [Behavioral Interview Handbook](https://www.techinterviewhandbook.org/behavioral-interview) - How software engineers prepare stories for behavioral rounds.
- [Why the Behavioral Matters](https://www.hellointerview.com/learn/behavioral/course/why-the-behavioral-matters) - What interviewers score in behavioral rounds, written by a former Meta hiring chair.

## Mock Interviews

- [interviewing.io](https://interviewing.io) - Anonymous mock interviews with engineers from large technology companies.
- [Pramp](https://www.pramp.com) - Free peer mock interviews for coding and system design.

## Company Preparation

- [How Google Hires](https://www.google.com/about/careers/applications/how-we-hire) - Google's description of its hiring process and interviews.
- [Meta Careers](https://www.metacareers.com) - Official Meta jobs site, including engineering roles.
- [Amazon Leadership Principles](https://www.amazon.jobs/content/en/our-workplace/leadership-principles) - Principles Amazon uses to evaluate behavioral interviews.
- [Netflix Culture](https://jobs.netflix.com/culture) - Culture memo Netflix uses when hiring.
- [Apple Careers](https://www.apple.com/careers/us) - Official Apple jobs site for roles in the United States.
- [Microsoft Careers](https://careers.microsoft.com) - Official Microsoft jobs site.
- [Levels.fyi](https://www.levels.fyi) - Compensation data for offers at large technology companies.
- [Blind](https://www.teamblind.com) - Anonymous discussions of interviews and offers at technology companies.

## Books

- [Cracking the Coding Interview](https://www.crackingthecodinginterview.com) - Coding questions and interview strategy by Gayle Laakmann McDowell.
- [Elements of Programming Interviews](https://elementsofprogramminginterviews.com) - Problems grouped by data structure, with worked solutions.
- [Designing Data-Intensive Applications](https://dataintensive.net) - Foundations of reliable, scalable data systems, by Martin Kleppmann.
- [System Design Interview](https://www.amazon.com/System-Design-Interview-Insiders-Guide/dp/1736049119) - Alex Xu's illustrated guide to common system design questions.
