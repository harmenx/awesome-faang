# Awesome FAANG Interview Resources [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> Software engineering interview preparation for large technology companies.

A typical loop at Google, Meta, Amazon, Apple, Netflix, or Microsoft has an online assessment or phone screen, then several coding rounds, a system design round for mid-level and senior roles, and a behavioral round. Each section below opens with a note on when it matters and how to use it, so you can plan your preparation rather than collect links.

Alongside the list are [original guides](guides/README.md): a [study plan](guides/study-plan.md), [twenty coding patterns with tested Python templates](guides/coding-patterns.md), a [system design playbook](guides/system-design.md), a [behavioral story bank](guides/behavioral.md), and [company-by-company notes](guides/companies.md).

## Start Here

Pick one study plan and follow it. Switching between plans is the most common way to lose weeks.

- [Tech Interview Handbook](https://www.techinterviewhandbook.org) - Practical preparation guide for software engineering interviews.
- [Grind 75](https://www.techinterviewhandbook.org/grind75) - Customizable 75-question coding plan ordered by study time.
- [NeetCode Roadmap](https://neetcode.io/roadmap) - Visual order for learning coding topics, each with a problem list.
- [Coding Interview University](https://github.com/jwasham/coding-interview-university) - Long self-study plan covering the computer science behind interviews.

## Coding Practice

Coding rounds make up most of a loop at every large company. Solving a focused set of problems well, and explaining them out loud, beats solving many problems quickly.

- [LeetCode](https://leetcode.com) - Coding problems with company tags, contests, and editorials.
- [NeetCode](https://neetcode.io) - Video walkthroughs and a topic roadmap for coding interviews.
- [Blind 75](https://leetcode.com/discuss/general-discussion/460599/blind-75-leetcode-questions) - Original list of 75 frequently asked coding questions.
- [LeetCode Patterns](https://seanprashad.com/leetcode-patterns) - Free coding questions grouped by the pattern that solves them.
- [Striver's A2Z DSA Sheet](https://takeuforward.org/prep-hub/strivers-a2z-dsa-sheet) - Free ordered problem list from basics to advanced topics, with video solutions.
- [Codeforces](https://codeforces.com) - Timed contests that build speed under pressure.

## Coding Patterns and Courses

Most interview problems are variations on a few dozen patterns. Learning to recognize the pattern is the skill these courses teach.

- [Interview Cake](https://www.interviewcake.com) - Interactive lessons that teach how to derive coding solutions.
- [AlgoMonster](https://algo.monster) - Pattern-first course for coding interview questions.
- [Grokking the Coding Interview](https://www.educative.io/courses/grokking-coding-interview) - Interactive course covering the patterns behind coding questions.
- [Hello Interview Coding](https://www.hellointerview.com/learn/code) - Visual lessons on coding patterns used in interviews.
- [AlgoExpert](https://www.algoexpert.io) - Curated questions with video explanations and a built-in coding workspace.
- [Beyond Cracking the Coding Interview free chapters](https://interviewing.io/blog/nine-free-chapters-of-beyond-cracking-the-coding-interview) - Nine free chapters of the 2025 sequel to Cracking the Coding Interview.

## Data Structures and Algorithms

For filling gaps in the fundamentals. Use these when a pattern course assumes knowledge you do not have yet.

- [Big-O Cheat Sheet](https://www.bigocheatsheet.com) - Time and space complexity for common data structures and algorithms.
- [VisuAlgo](https://visualgo.net/en) - Animations of data structures and algorithms.
- [CP-Algorithms](https://cp-algorithms.com) - Explanations and implementations of algorithms used in interviews.
- [USACO Guide](https://usaco.guide) - Free, structured guide to algorithms from beginner to advanced, with practice problems.
- [MIT 6.006 Introduction to Algorithms](https://ocw.mit.edu/courses/6-006-introduction-to-algorithms-spring-2020) - Full university course with lectures, notes, and problem sets.
- [Algorithms, 4th Edition](https://algs4.cs.princeton.edu/home) - Princeton's companion site with code and notes for the textbook.

## Online Assessments

Many applications start with a timed online assessment before any human interview. Practise on the platform you will be tested on so the editor and the time limit are not a surprise.

- [HackerRank](https://www.hackerrank.com) - Practice problems on the platform many companies use for online assessments.
- [CodeSignal Learn](https://codesignal.com/learn) - Practice paths on the platform behind CodeSignal's general coding assessment.

## System Design

Usually starts at mid-level roles and carries more weight with seniority. Learn a repeatable structure first, then practise common problems end to end.

- [System Design Primer](https://github.com/donnemartin/system-design-primer) - Open study guide for large-scale system design interviews.
- [System Design in a Hurry](https://www.hellointerview.com/learn/system-design/in-a-hurry/introduction) - Short system design course written by interviewers from large technology companies.
- [Hello Interview problem breakdowns](https://www.hellointerview.com/learn/system-design/in-a-hurry/problem-breakdowns) - Worked answers to common system design questions, level by level.
- [ByteByteGo](https://bytebytego.com) - Diagrams and written guides for system design interviews.
- [Grokking the System Design Interview](https://www.educative.io/courses/grokking-the-system-design-interview) - Interactive course of common system design questions.
- [System Design Course](https://github.com/karanpratapsingh/system-design) - Free illustrated course on designing systems at scale.
- [Awesome System Design Resources](https://github.com/ashishps1/awesome-system-design-resources) - Curated concepts, articles, and practice problems for system design.
- [Aced system design guide](https://www.aced.io/blog/system-design-interview-guide) - Preparation guide and question bank from Aced, formerly Exponent.
- [interviewing.io system design guide](https://interviewing.io/guides/system-design-interview) - Long free guide to system design interviews from senior interviewers.
- [Google SRE Book](https://sre.google/sre-book/table-of-contents) - Free book on building and operating reliable production systems.
- [AWS Well-Architected](https://aws.amazon.com/architecture/well-architected) - Official framework for secure, reliable, and efficient cloud systems.

## Low-Level Design

Some companies ask for object-oriented design of a small system, such as a parking lot or a rate limiter, in place of or alongside a coding round.

- [Grokking the Low Level Design Interview](https://www.educative.io/courses/grokking-the-low-level-design-interview-using-ood-principles) - Object-oriented design questions and worked solutions.
- [Awesome Low-Level Design](https://github.com/ashishps1/awesome-low-level-design) - Design patterns and worked low-level design problems with code.
- [Refactoring.Guru design patterns](https://refactoring.guru/design-patterns) - Illustrated catalog of design patterns with examples in several languages.

## Engineering Blogs and Papers

Real systems at the companies you are interviewing with. Citing how a company actually solved a problem gives a system design answer depth.

- [Amazon Builders' Library](https://builder.aws.com/learn/topics/builders-library) - Articles by Amazon engineers on how they build and operate services.
- [Netflix TechBlog](https://netflixtechblog.com) - Netflix engineering on streaming, data, and reliability.
- [Meta Engineering](https://engineering.fb.com) - Posts from Meta engineers on infrastructure, data, and production systems.
- [High Scalability](https://highscalability.com) - Long-running blog of architecture case studies from large services.
- [Cloudflare Blog](https://blog.cloudflare.com) - Detailed posts on networking, edge computing, and incident reviews.
- [Dynamo](https://www.allthingsdistributed.com/files/amazon-dynamo-sosp2007.pdf) - Amazon's paper on a highly available key-value store.
- [MapReduce](https://research.google/pubs/mapreduce-simplified-data-processing-on-large-clusters) - Google's paper on batch processing across large clusters.
- [Bigtable](https://research.google/pubs/bigtable-a-distributed-storage-system-for-structured-data) - Google's paper on a distributed storage system for structured data.
- [Spanner](https://research.google/pubs/spanner-googles-globally-distributed-database-2) - Google's paper on a globally distributed, strongly consistent database.

## Behavioral Interviews

Weighs heavily at Amazon and at senior levels everywhere. Prepare a handful of specific stories with measurable results and practise telling them in a few minutes each.

- [Behavioral Interview Handbook](https://www.techinterviewhandbook.org/behavioral-interview) - How software engineers prepare stories for behavioral rounds.
- [Why the Behavioral Matters](https://www.hellointerview.com/learn/behavioral/course/why-the-behavioral-matters) - What interviewers score in behavioral rounds, written by a former Meta hiring chair.
- [Amazon Leadership Principles](https://www.amazon.jobs/content/en/our-workplace/leadership-principles) - Principles Amazon uses to evaluate behavioral interviews.
- [StaffEng](https://staffeng.com) - Stories and guides on staff-plus roles, useful for senior behavioral rounds.

## Role-Specific Preparation

Front-end, data, and machine learning roles add their own rounds on top of, or in place of, general coding.

- [GreatFrontEnd](https://www.greatfrontend.com) - Front-end interview questions, from JavaScript utilities to UI components and front-end system design.
- [Front End Interview Handbook](https://www.frontendinterviewhandbook.com) - Free guide to front-end interview formats and topics.
- [DataLemur](https://datalemur.com) - SQL and data science interview questions asked at large technology companies.
- [Machine Learning Interviews Book](https://huyenchip.com/ml-interviews-book) - Free book on machine learning roles, interview formats, and practice questions.
- [ML System Design in a Hurry](https://www.hellointerview.com/learn/ml-system-design/in-a-hurry/introduction) - Short course on machine learning system design interviews.

## Mock Interviews

Practising out loud with another person finds problems that solo practice misses, such as going silent or skipping the clarifying questions.

- [interviewing.io](https://interviewing.io) - Anonymous mock interviews with engineers from large technology companies.
- [Pramp](https://www.pramp.com) - Free peer mock interviews for coding and system design.
- [Aced](https://www.aced.io) - Courses, coaching, and mock interviews for engineering and product roles, formerly Exponent.

## Company Preparation

Processes change often. Treat these as a starting point and confirm the format of each round with your recruiter. In 2025 Google added at least one in-person round for engineering candidates, and Meta began piloting a coding round that allows an AI assistant.

- [How Google Hires](https://www.google.com/about/careers/applications/how-we-hire) - Google's description of its hiring process and interviews.
- [Google Build Your Future](https://www.google.com/about/careers/applications/buildyourfuture/resources) - Google's free learning resources for technical candidates, formerly the Tech Dev Guide.
- [Meta Careers](https://www.metacareers.com) - Official Meta jobs site, including engineering roles.
- [How Amazon Hires](https://www.amazon.jobs/content/en/how-we-hire) - Amazon's overview of its hiring process and how to prepare for each stage.
- [Netflix Culture](https://jobs.netflix.com/culture) - Culture memo Netflix uses when hiring.
- [Apple Careers](https://www.apple.com/careers/us) - Official Apple jobs site for roles in the United States.
- [Microsoft Careers](https://careers.microsoft.com) - Official Microsoft jobs site.
- [IGotAnOffer](https://igotanoffer.com) - Company-specific interview guides with example questions for each round.
- [interviewing.io hiring process guides](https://interviewing.io/guides/hiring-process) - How the interview process works at specific large technology companies.

## Resumes and Applications

A referral or a clear one-page resume gets you into the loop. Keep it short, lead with impact, and use numbers where you have them.

- [Tech Interview Handbook resume guide](https://www.techinterviewhandbook.org/resume) - How to write a software engineering resume that passes screening.
- [The Tech Resume Inside Out](https://thetechresume.com) - Guide to tech resumes from the hiring manager's side, by Gergely Orosz.
- [Jake's Resume](https://www.overleaf.com/latex/templates/jakes-resume/syzfjbzwjncs) - Widely used one-page LaTeX resume template.
- [New Grad Positions](https://github.com/SimplifyJobs/New-Grad-Positions) - Community-updated list of open new graduate software roles.

## Offers and Negotiation

Initial offers at large companies usually have room to move, especially in equity and signing bonus. Competing offers are the strongest lever.

- [Levels.fyi](https://www.levels.fyi) - Compensation data for offers at large technology companies.
- [Blind](https://www.teamblind.com) - Anonymous discussions of interviews and offers at technology companies.
- [Ten Rules for Negotiating a Job Offer](https://haseebq.com/my-ten-rules-for-negotiating-a-job-offer) - Essay on how to negotiate without risking the offer.
- [How Not to Bomb Your Offer Negotiation](https://haseebq.com/how-not-to-bomb-your-offer-negotiation) - Follow-up essay walking through the negotiation conversation step by step.
- [Tech Interview Handbook negotiation guide](https://www.techinterviewhandbook.org/negotiation) - How to negotiate salary, equity, and signing bonus for engineering offers.

## Books

- [Cracking the Coding Interview](https://www.crackingthecodinginterview.com) - Coding questions and interview strategy by Gayle Laakmann McDowell.
- [Elements of Programming Interviews](https://elementsofprogramminginterviews.com) - Problems grouped by data structure, with worked solutions.
- [Grokking Algorithms](https://www.manning.com/books/grokking-algorithms-second-edition) - Illustrated introduction to common algorithms for self-taught engineers.
- [The Algorithm Design Manual](https://www.algorist.com) - Steven Skiena's practical guide to designing algorithms, with a catalog of problems.
- [Introduction to Algorithms](https://mitpress.mit.edu/9780262046305/introduction-to-algorithms) - Standard algorithms reference, known as CLRS.
- [Designing Data-Intensive Applications](https://dataintensive.net) - Foundations of reliable, scalable data systems, by Martin Kleppmann.
- [System Design Interview](https://www.amazon.com/System-Design-Interview-Insiders-Guide/dp/1736049119) - Alex Xu's illustrated guide to common system design questions.
